# 模型接入与工具链交接模板

## 任务身份

目标仓库/提交/dirty、目标样例、平台/SoC、任务和运行语言、用户私人应用或公开仓库贡献。安装的 Skills Pack 和 OE Pack 分别记录来源版本，不与目标模型版本混淆。

## 输入输出对照

| 组件/节点 | 源模型 | 编译产物/runtime | sample 期望 | 差异和处理 |
|---|---|---|---|---|
| 输入名称和个数 | 从真实模型提取 | 从 metadata 提取 | 从 wrapper 读取 | 未知不推断 |
| shape/dtype/layout | 固定/动态约束 | 对齐/布局/存储要求 | 当前代码假设 | 明确修改点 |
| 预处理 | 色彩/采样率/归一化/历史堆叠 | 编译器吸收的步骤 | host 剩余职责 | 禁止重复归一化 |
| 输出语义与次序 | 原始浮点输出 | 量化/反量化/节点次序 | decode/标签/后处理 | 逐组件核对 |
| 状态与多组件依赖 | encoder/decoder/tokenizer/历史缓存 | 哪些运行在何处 | 组件间传递 | 缺一项不算完成 |

## 委托输入

模型定义/权重/上游版本与哈希；浮点可复现基线；校准/验证数据来源与许可；每个输入协议；目标格式/runtime；精度接受条件与性能口径；输出根；批准的安装/上传/覆盖/资源预算。没有模型定义不能假定 `.pt` 可直接运行或训练。

## 返回核对

原始收据路径与哈希；模型架构与文件格式；真实工具版本；compiler metadata；模型/数据身份；实际运行的命令及结果；已测任务/平台/runtime；未运行与失败项。读取原文件，不重新编造同名 JSON。

## 接入后新增验证

具体修改文件/接口；同输入基线比较；不同任务与 Python/C++ 覆盖；文档/下载/Manifest 影响；由接入改变的部分必须重新验证。输出工具链状态和 Model Zoo 接入状态两个结论。
