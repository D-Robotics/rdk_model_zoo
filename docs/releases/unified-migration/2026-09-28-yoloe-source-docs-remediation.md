## Filename deviation from the review text (flagged for reviewer decision)

The review suggested names "like `source_s11_result.jpg` /
`source_s26_result.jpg`". The repository's global `.gitignore` rule
`*_result.jpg*` matches exactly that shape, so those files would be
untrackable (verified with `git check-ignore`), and editing the shared root
`.gitignore` is outside this task's declared file scope. The copies therefore
use `source_s11_result_figure.jpg` / `source_s26_result_figure.jpg` —
identical bytes, equally distinct from the runtime-generated
`test_data/result.jpg`, and trackable with no ignore change (verified exit
1). If the reviewer prefers the literal names, the only follow-up needed is a
scoped `.gitignore` negation pair; the bytes and docs would not change.
