## 已修复问题与未闭合事项

- Python 3.10 下旧 YOLO 主入口的嵌套 f-string 语法问题；保存修复前编译
  失败日志，新版真实 Python 3.10/3.12 编译通过。
- HTTP 截断内容误装为完整模型、S YOLO26 旧库入口在其他 cwd 导入失败；
  独立审查复现，补回归测试并修复。
- ResNet 原有 letterbox 实际用 linear；新实现曾错误使用 nearest。
  修正后 20 组旧新 NV12 字节对照一致，包括默认白狼图片。
- ResNet 实际输出形状/类型、元数据可选字段默认值、默认标签文件解析均
  纳入检查；最终源码已统一验证。
- SDK 的实际 dtype 为带 `.name` 的枚举；首轮板测失败后按 NV12/U8/F32
  实际类型修正。失败记录 `*-pilot-attempt1.log` 保留。
- 第二轮检测数值已通过，但测试上传包遗漏标签文件，导致可视化命令失败；
  这是测试打包错误，补齐原资源后原生命令通过。`*-pilot-attempt2.log` 保留。
- X5 ResNet 原始 `prob` 输出看起来已归一化；旧源码仍调用主机 softmax。
  新实现明确保留 `legacy_softmax`，不据张量名称推定图内语义，也不静默
  改成另一套分数。图/转换源缺失仍是语义确认缺项，不是本次修复结论。
- 未改的 YOLO 评估器及非 DFL 任务库路径，尚未全部接入新执行目标门禁。
  主入口及本批 Runner 的检查不能替代后续逐任务审查。
