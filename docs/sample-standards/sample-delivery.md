# Model Zoo Sample 交付规范

本规范适用于仓库内维护的 Sample。模型专有算法留在 Sample，跨模型公共能力只维护在根目录 `utils/`。README 直接面向使用者，代码直接面向阅读、集成和二次开发。

## 1. Sample README 的固定阅读顺序

1. **模型介绍与来源**：模型任务、基本原理、作者或项目、论文和上游实现链接；说明本目录提供哪些模型变体。
2. **目录结构**：列出当前目录实际存在的子目录和关键文件，逐项说明用途。
3. **使用方法**：适用板卡和模型、环境安装、模型准备、完整运行命令及输出；随后链接详细子目录说明。

英文 `README.md` 与中文 `README_cn.md` 使用相同章节顺序、命令、参数和支持范围。
保留显式 HTML 锚点以便引用；章节排列服从以上阅读顺序。

## 2. 子目录 README

每个子目录先说明用途和输入输出，再给当前目录结构，最后给完整操作步骤。

| 目录 | 必须说明的操作 |
| --- | --- |
| `model/` | 模型/板卡对应关系、下载或准备命令、伴随文件、最终保存路径 |
| `conversion/` | 原始权重获取、ONNX 导出、工具链环境、校准数据准备、量化配置、编译命令、输出模型路径及使用方式 |
| `runtime/python/` | 环境与依赖、模型准备、运行命令、完整 CLI 参数、结果说明、模型类 predict 和必要的三阶段集成示例 |
| `runtime/cpp/` | SDK/编译依赖、构建命令、模型准备、运行参数、输出与调用接口 |
| `evaluator/` | 数据集准备、依赖、运行命令、指标定义、结果文件和读取方式 |
| `test_data/`、`tests/` | 若有 README，说明所含数据或测试的用途及实际运行方式 |

每组命令说明工作目录、输入来源、参数和输出位置。主 README 提供一条完整快速运行路径；子 README 不能仅用“参考其他模型”代替本目录操作。
同一模型有多种板卡/工具链配方时分小节列出，完整保留每条原始配方的命令、依赖、版本、配置、链接和图片，仅调整已经改变的路径。

## 3. 交付口径

- 写当前可使用的模型、接口、文件和操作步骤。
- 环境条件写成具体安装/准备要求，错误处理写成真实问题的解决步骤。
- 不写迁移、重构、兼容层来源、历史分支差异、实现防御说明、审计结果或待验收状态。
- 不用“仅用于证明”“不代表”“不保证”“尚未验证”等维护口径包装正常操作。
- 不用删除真实技术前提、虚构支持范围或删减量化步骤来满足文字要求。
- 迁移映射、测试记录和源码来源沿革放在独立维护文档。模型论文、上游链接、许可证和必须保留的第三方归属仍属于交付文档。

## 4. Python Runtime

- `main.py` 负责参数传递、显式构造模型、调用 `predict` 和展示结果。
- `classify.py`、`detect.py`、`segment.py` 等模型/任务文件包含初始化、preprocess、infer、postprocess、predict 的真实流程。
- 普通单任务 Sample 默认使用 `main.py`、`cli.py`、模型类三个 Python 文件；模型特有解码复杂时可增加有明确职责的文件。
- 按 [Runtime 代码规范](runtime-code.md) 组织文件；删除只转发公共 import 的 Sample 文件，不逐函数拆文件。
- SDK 封装、读取 BGR 图、标签校验、通用张量和数学函数直接复用 `utils/py_utils`。
- 板卡和模型选择显式传递，实际 SDK 执行核查板卡身份；前后处理遵守各制品的输入输出契约。
- Google-style docstring 按 `Model_Zoo_Repository_Guidelines.md` 编写；参数、返回值、异常及张量语义与实现一致，行内注释使用英文。

## 5. 公共目录

```text
utils/
├── py_utils/       # Python 公共能力与测试
└── c_utils/        # C/C++ 公共能力
scripts/tools/     # 独立维护程序
samples/<领域>/<模型>/
├── model/
├── conversion/
├── runtime/
├── evaluator/
└── test_data/
```

相同能力只维护一份实现。公共库不得依赖某个 Sample 的入口；轻量的参数查看和模型列举不触发图像库或 SDK 加载。

## 6. 验收

核对所有 README 的章节顺序、双语内容、路径、命令及源码参数；逐条核对转换配方保留情况。
运行公共库与受影响 Sample 的主机测试、CLI 检查、文档契约和适用 C++ 构建测试。
主机模拟和板端真实运行分别记录，不将一者结果写成另一者结果。
