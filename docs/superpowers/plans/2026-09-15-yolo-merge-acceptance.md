## 验证

新增 Sample 测试 20 项通过（49.867 秒）；原 S 分类公共入口回归 2 项通过。

- 主机测试覆盖平台识别、显式参数优先、资产集合、输入协议、实际预处理绑定、旧模块导入、旧 Pose 三项接口、CHW/HWC 分割原型、opset 传递、跨工作目录 CLI、Shell 语法与真实脚本 dry-run。
- 原 S 分类名称测试改为公共入口回归，覆盖 S100/S100P/S600、YOLOv8/YOLO11 的 224 分类文件名。
- 独立对照原始 X5/S 源码的 20 项合成后处理结果一致（检测/姿态/分割：空输出、重叠、随机；分类：随机 logits）。这不替代真实模型推理。

- X5 全量下载 dry-run 为 67 个 .bin 文件；下载 URL 与目录发布资产对照，不联网下载模型。
- Python 编译和 Git whitespace 检查通过；无其他 Sample 源码改动。
