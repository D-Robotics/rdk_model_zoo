# BPU Sample source documentation

This directory provides **BPU Sample source API reference documentation** for the Python and C/C++ implementations under the repository-root `samples/` and `utils/` directories, delivered as a static HTML site:

- Users: build the documentation from the source tree with the steps below (Python 3 + Sphinx/Doxygen).
- Developers: rebuild and package the documentation locally.

## 1. Browse the documentation

- Locally with a graphical interface: open
    `docs/source_reference/sphinx/build/html/index.html` in a browser.
- From the command line, locally or remotely:

    ```bash
    python3 -m http.server 8000 --directory docs/source_reference/sphinx/build/html
    ```

    Visit `http://localhost:8000` in a browser.

- For a remote server without a graphical interface, forward the port from a local terminal first, then browse as above:

    ```bash
    # For example: ssh -L 8000:localhost:8000 sunrise@192.168.1.1
    ssh -L 8000:localhost:8000 user@remote_host
    ```

## 2. Documentation contents

- **Python API** (`python/` + `autoapi/`): sphinx-autoapi statically scans all Python sources in the repository-root `samples/` and `utils/` directories, excluding `__pycache__`, `tests` and `dist`. Sample navigation has two levels: **task (vision / llm / robotics / speech / vla) → model**. The utils entry point is `python/utils/`.
- **C/C++ API** (`doxygen_site/`): Doxygen recursively scans C/C++ source files (`*.c`, `*.cc`, `*.cpp`, `*.h`, `*.hpp`, etc.) under the repository-root `samples/` and `utils/` directories, excluding `build/` and `CMakeFiles/`. Enter from the site home or the `cpp/` page.

## 2. Build the documentation

### Directory structure

```text
docs/source_reference/
├── README.md                        # This guide
├── doxygen/
│   └── Doxyfile                     # Doxygen: INPUT=../../../samples/ and ../../../utils/, output ../sphinx/build/html/doxygen_site
└── sphinx/
    ├── Makefile                     # Sphinx build entry (make html)
    ├── make.bat                     # Equivalent Windows entry
    ├── source/                      # Documentation sources (rst)
    │   ├── conf.py                  # Sphinx: autoapi.extension, sphinx.ext.napoleon; sphinx_rtd_theme; scans root samples/ and utils/
    │   ├── index.rst                # Site home (C/C++ and Python entries)
    │   ├── cpp/doxygen_ref.rst      # C/C++ entry linking to doxygen_site/html/
    │   ├── python/                  # Python navigation (sample navigation generated by gen_samples_nav.py)
    │   └── autoapi/                 # Generated by AutoAPI during the build (build output)
    ├── tools/
    │   └── gen_samples_nav.py       # Generates sample navigation from AutoAPI output
    └── build/                       # Build output (html / doctrees / doxygen_site)
```

### Build environment

The C/C++ documentation requires Doxygen:

```bash
sudo apt install -y doxygen        # Ubuntu/Debian; use brew install doxygen on macOS
```

Install Python dependencies in a virtual environment you create and manage:

```bash
python3 -m venv ~/.venvs/bpu-docs
source ~/.venvs/bpu-docs/bin/activate
pip install -U sphinx sphinx-autoapi sphinx-rtd-theme
```

Dependencies match `sphinx/source/conf.py`: the `autoapi.extension` extension for static Python scanning, the built-in `sphinx.ext.napoleon` extension for Google/NumPy-style docstrings, and the `sphinx_rtd_theme` theme.

### Build steps

Starting at the repository root, run these steps in order:

```bash
# 1. First Sphinx build: scan Python sources and generate AutoAPI documentation sources
#    Inputs: root samples/ and utils/ (autoapi_dirs in conf.py)
#    Outputs: sphinx/source/autoapi/** (rst) and sphinx/build/html/
cd docs/source_reference/sphinx
make html

# 2. Doxygen build: scan C/C++ sources
#    Inputs: ../../../samples/ and ../../../utils/ (INPUT in Doxyfile, relative to doxygen/)
#    Output: sphinx/build/html/doxygen_site/html/
cd ../doxygen
doxygen Doxyfile

# 3. Generate sample navigation
#    Input: sphinx/source/autoapi/samples/**/index.rst
#    Outputs: sphinx/source/python/samples/index.rst and <task>/<model>/index.rst
cd ../sphinx
python3 tools/gen_samples_nav.py .

# 4. Second Sphinx build: include navigation and generate the final HTML site
#    Output: docs/source_reference/sphinx/build/html/index.html
make html
```
