# 评估基于 X3 原生 API 的 HBM 常用接口兼容层

状态：accepted-for-evaluation，用户认可有限可行性验证后决定推广；并非已批准完整 SDK 复刻或认定技术可行。

优先评估基于 X3 C/C++ 推理 API 提供 hbm_runtime 常用调用接口子集，以减少多个 Sample 的底层调用差异。接口名称兼容不表示模型格式兼容，输入输出、量化、内存和异常语义必须在对应 SDK 与实机上验证，X3 仍使用适合自身架构的资产。

这比散落的 pyeasy_dnn 调用更可能集中维护底层行为，但引入绑定、构建与资源管理责任。有限验证通过后才推广；若无法满足必要语义或安装维护成本，保留 pyeasy_dnn 薄适配完成基础迁移。首版不要求线程安全、异步、零拷贝或完整调度能力，不覆盖系统 hbm_runtime 模块。
