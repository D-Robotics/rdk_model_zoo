# 统一源码发版，以平台矩阵声明支持与验证范围

状态：accepted，用户在 Q11 选择方案 A。

合并后的源码采用统一版本，每个发布指向确定的仓库快照，并声明各平台的支持和验证范围；不再为新开发分别维护 X3、X5、S 的源码发布版本线。这样新增板卡或主力板卡变化不需要重组主线和版本体系，同时各平台可以在不同版本中按需更新。

Skills 独立发版，模型资产按需要更新，均不要求随每次源码发版重新生成。保留既有历史 tag 与模型来源。平台矩阵必须区分支持声明与实际验证范围，不能将一个平台、任务或代表规格通过扩大为所有配置通过。

具体 tag 命名及 CI 隔离尚未确定：旧 Skills 方案对裸 vX.Y.Z 的使用需要与统一源码版本协调，并在实施前核对 Hub 当前约束。
