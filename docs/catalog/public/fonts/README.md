# Noto Sans SC

Self-hosted WOFF2 subsets for weights 400, 500 and 600. The browser requests only the Unicode subsets needed by the page.

Source: https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;600&display=swap
Fetched 2026-09-11; font URLs served by fonts.gstatic.com.
License: SIL Open Font License 1.1; full text in OFL.txt, sourced from https://github.com/google/fonts/tree/main/ofl/notosanssc.

Runtime pages do not request Google Fonts or any external font service.

The CSS exposes Catalog Chinese UI with Chinese-only Unicode ranges. ASCII letters and digits are excluded so the existing Latin UI and display fonts remain in use.
