# 在线模型目录维护

网站源码收录在文档配套目录，仓库根目录仅保留面向模型样例开发的主要内容。发布清单位于 [../manifests/](../manifests/)，完整维护入口见 [文档索引](../README.md)。

从仓库根目录运行（Node.js 22）：

```bash
cd docs/catalog
npm ci
npm run dev
```

验证和生产构建：

```bash
npm run check
```

构建输出为 `docs/catalog/dist/`；依赖、构建输出和生成的 `public/data/catalog.json` 不提交。GitHub Actions 使用同一目录安装、验证与发布，线上地址保持不变。

生成器从固定来源读取多平台清单，兼容旧 Tag 的 `release/`、`docs/release/` 路径与当前布局的 `docs/manifests/`。目录搬迁不重打 Tag，不改变模型文件地址，也不重新计算 Benchmark。

发布时，X5 清单取自当前发布检出，S/X3 取自 `docs/manifests/catalog-sources.json` 指定的附注 Tag。升级 S/X3 后需要显式更新此文件再发布 X5；不会自动读取活动分支。构建会核对各平台声明的清单汇总，Pages 按 `platform_tags.x5` 验证发布身份。

## UI 与数据的边界

本轮已恢复收录完成规范化的 YOLOE，移除早期方案中的专门排除规则；它与其他 Sample 使用相同的来源、Schema 和完整性校验。

- `app.ts` 组合目录和独立详情，`ui/navigation.ts` 管理可分享的查询参数。
- `ui/filters.ts` 提供硬件快捷栏、任务侧栏、搜索和手机筛选草稿；任务分组集中在 `catalog/task-groups.ts`，新增任务使用稳定 ID，未归类项进入其他任务。
- `catalog/card-view-model.ts` 适配现有数据并生成当前硬件范围的卡片摘要；`ui/model-card.ts` 只负责卡片展示。模型卡片采用纯文字布局，不展示图片或装饰图形。
- 详情由页面、规格表、精度对照、文件下载和来源组件组合；数值格式继续复用 `catalog/metric-display.ts`。
- 基础样式位于 `styles.css`，目录与卡片、详情分别维护局部样式。页面支持系统／浅色／深色主题以及中英文。

数据刷新以原始 README、评测文档和下载脚本为依据，修正清单中的条件、文件关联与遗漏记录；不得猜测测试值或下载地址。历史 S/X3 标签保持不可变，已确认的遗漏在 `scripts/*catalog-errata.ts` 中按具体标签应用，每条新增记录保留原始来源；子模块证据使用标签所固定的提交及仓库地址。原始发布汇总先校验，修订后的目录另行生成汇总。后续对应平台发布时应将修订纳入其权威清单，再移除过期修订层。

未明确开发板的工具链、共享测试记录显示在“其他测试记录”，不猜测硬件。延迟与吞吐量以外的指标显示在“其他性能指标”，保留原始单位和测试范围。上下界、近似值、浮点/量化阶段及线程数均属于数据含义，不能为了合并行而丢弃。后续维护请遵循本节的数据边界约定，不要在 DOM 组件中填入模型特例或 Benchmark 数字。

CPU 后处理与同配置的 BPU 延迟/FPS 在同一行以独立列展示；计时范围差异不应产生重复模型行，也不能将独立耗时相加推导端到端结果。CPU 并发条件不进入 BPU 线程列。


同一平台、任务、输入及模型产物配置只展示一行。encoder/decoder/CPU 后处理等阶段分别成列；不同运行时和 mean/p50/p95 等统计值在单元格内保留各自的测试条件，性能和精度共用配置行。不得跨实际模型配置合并，不得相加独立计时推导端到端结果。全量回归检查每个配置只出现一次，且原始指标保留在该行或其详情中。

### 首页概览与代表页（2026-09-11）

首页从完整 catalog 计算模型系列与具体模型数量；具体模型按平台内 variant 计数，平台卡片可跳转筛选。字体通过 public/fonts 的 Noto Sans SC WOFF2 Unicode 子集随站点提供，附 OFL 授权。

所有模型族默认显示单线程比较，其余已测线程可展开。凡在某列每个已有取值的单元格中重复出现的运行时、统计口径与计时范围（如 `hrt_model_exec`、`BPU task`、`single-core CPU`），都从单元格中移出，统一记录在表格下方的“测试条件”中，并给出对应来源链接；仅当源记录确实写明时才列出，不做跨平台推断，也不假定 NV12 或性能模式。缺失的精度或性能统一显示为 `—`，图例分别标注“未记录精度”与“未记录性能”，完整说明保留在 `title` / `aria-label` 中。Paraformer 按阶段对照 Python/C++ UCP；HIMLoco 展示运行时统计矩阵并单独收起编译器估算；SigLIP 可选择配置，分别展示性能和精度，其未归属到具体板卡的共享精度分布按记录逐条折叠，仍可展开查看。所有原始指标及来源保留在各配置详情中。
