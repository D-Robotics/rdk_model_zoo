# Model Download

## Download Method

Run the `download_model.sh` script to automatically download the HBM model file:

```bash
bash download_model.sh
```

The model will be downloaded to `/opt/hobot/model/<soc>/basic/kws.hbm`.

## Manual Download

To download manually, select the corresponding URL based on your platform:

- S100: `https://archive.d-robotics.cc/downloads/rdk_model_zoo/rdk_s100/kws/kws.hbm`
