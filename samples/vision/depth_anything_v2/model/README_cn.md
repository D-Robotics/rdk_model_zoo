# Depth Anything V2 模型文件

本目录用于下载和存放 Depth Anything V2 在 RDK S100 上使用的 HBM 模型。

## 下载命令

```bash
cd samples/vision/depth_anything_v2/model
bash download_model.sh s100
```

下载成功后，模型文件为：

```text
model/s100/depth_any.hbm
```

## 模型说明

| 文件 | 说明 |
| --- | --- |
| `s100/depth_any.hbm` | Depth Anything V2 RDK S100（Nash-e）HBM 模型 |
