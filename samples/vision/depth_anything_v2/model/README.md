# Depth Anything V2 Model Files

This directory downloads and stores the Depth Anything V2 HBM model for RDK S100.

## Download Command

```bash
cd samples/vision/depth_anything_v2/model
bash download_model.sh s100
```

After a successful download, the model file is:

```text
model/s100/depth_any.hbm
```

## Model Description

| File | Description |
| --- | --- |
| `s100/depth_any.hbm` | Depth Anything V2 HBM model for RDK S100 (Nash-e) |
