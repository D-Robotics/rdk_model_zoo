# ResNet152 Model

Use `download_model.sh` to download the public S100 HBM model into this sample directory.

```bash
bash download_model.sh s100
```

The downloaded file is:

```text
model/s100/resnet152_224x224_nv12.hbm
```

The Python runtime uses this sample-local path by default.
