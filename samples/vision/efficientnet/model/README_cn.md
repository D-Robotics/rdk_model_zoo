# EfficientNet-Lite 模型

使用 `download_model.sh` 下载公开 S100 HBM 模型到当前 sample 目录。

```bash
bash download_model.sh s100 lite0
```

下载全部变体：

```bash
bash download_model.sh s100 all
```

支持的变体为 `lite0`、`lite1`、`lite2`、`lite3`、`lite4` 和 `all`。

| 变体 | 文件 |
| --- | --- |
| `lite0` | `s100/efficientnet_lite0_224x224_nv12.hbm` |
| `lite1` | `s100/efficientnet_lite1_240x240_nv12.hbm` |
| `lite2` | `s100/efficientnet_lite2_260x260_nv12.hbm` |
| `lite3` | `s100/efficientnet_lite3_300x300_nv12.hbm` |
| `lite4` | `s100/efficientnet_lite4_380x380_nv12.hbm` |
