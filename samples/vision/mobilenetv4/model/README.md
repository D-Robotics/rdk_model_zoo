# MobileNetV4 Model Download

Run the download script from this directory:

```bash
bash download_model.sh s100
```

The script downloads the S100 HBM files to `./s100/`:

| Model | URL |
| --- | --- |
| `mobilenetv4_small_224x224_nv12.hbm` | `https://archive.d-robotics.cc/downloads/rdk_model_zoo/rdk_s100/MobileNet/mobilenetv4_small_224x224_nv12.hbm` |
| `mobilenetv4_medium_256x256_nv12.hbm` | `https://archive.d-robotics.cc/downloads/rdk_model_zoo/rdk_s100/MobileNet/mobilenetv4_medium_256x256_nv12.hbm` |

This sample uses the public S100 HBM models.
