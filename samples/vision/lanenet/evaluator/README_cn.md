# LaneNet 评估边界

源 evaluator 目录只有占位说明。本次迁移提供可复现的主机契约检查，不虚构数据集评估器、实例聚类算法或精度结果。

<a id="dataset"></a>
## 数据集

保留的 [lane.jpg](../test_data/lane.jpg) 是演示输入，不是有标签的评估集。源 evaluator 未提供训练/验证划分、标注转换、数据集校验和或许可记录。四幅历史显示 PNG 也不是真值。后续数据集评估需要先定义标签、划分、前处理和车道实例匹配规则。

<a id="environment"></a>
## 环境

主机检查需要 Python、NumPy、OpenCV、PyYAML 和 C++17 编译器。原生单测使用伪头文件编译独立辅助模块及真实资源管理器，不需要板卡、HBM、OE 或厂商库。完整原生 SDK/OpenCV 编译属于另一项尚未执行的检查。实际推理环境参见 [Python](../runtime/python/README_cn.md) 或 [C++](../runtime/cpp/README_cn.md)。

<a id="command"></a>
## 命令

从仓库根目录执行：

```bash
python3 -m unittest discover -s samples/vision/lanenet/tests
```

该命令只执行主机夹具，不下载资产、不连接板卡。原生测试会使用本地 C++ 编译器构建并运行临时主机可执行文件。后续在 S100 准备原始结果时，使用上述运行文档中的命令，为每种实现选择新的结果目录。

<a id="metrics"></a>
## 检查内容

主机测试检查源前处理算术、元数据拒绝、保留精确类型的原始输出、结果独立所有权、二值 0/1 约束、显示舍入、输出路径冲突拒绝和转换准备。原生夹具还检查含填充的字节步长、溢出、角色歧义、超过 2^53 的 int64 序列化，以及注入失败后的资源释放。这些是实现契约，不是车道检测指标。

后续板端对照必须记录模型/图像精确摘要、板卡/运行库版本、完整输出元数据及原始数组。嵌入数值使用有依据并明确声明的容差，标签精确比较，显示图另行比较。Python 按名称、原生按形状/类型绑定，首先应确认实际角色对应关系。主机夹具不能证明任何板端容差、相等关系或精度门槛。

<a id="outputs"></a>
## 输出与证据

单测将检查结果输出到终端。运行结果格式见 [Python 结果](../runtime/python/README_cn.md#results)和[原生结果](../runtime/cpp/README_cn.md#results-interpretation)：保留 NPZ 名称映射或原生角色索引，不能只留截图。源审计记录于[迁移报告](../../../../docs/releases/unified-migration/2026-09-26-b8-lanenet-source-review.md)。

<a id="reference-results"></a>
## 参考结果

源转换说明记录过 200 帧 HRT 测试、14.245 ms 和 69.894 FPS。对应板卡镜像、运行库/工具链版本及资产摘要未固定；这是历史源记录，不是本次复测，也不是 Python/C++ 端到端延迟。[转换说明](../conversion/README_cn.md)保留其上下文及缺失前提。

当前主机实现阶段共有 22 项 sample 测试通过，其中包括三项原生辅助/资源/序列化夹具和四项原生启动器测试。该计数仅说明主机覆盖。真实板端推理、完整原生 SDK 构建、OE 编译、数据集精度和性能仍为 **not-run**。请重新执行上述命令获取当前 checkout 的结果，不应仅依赖静态计数。

<a id="boundaries"></a>
## 边界

尚未建立精度数字、车道实例指标、运行加速比或跨语言板端等价关系。源精度示意图片路径缺失，没有用虚构证据替代。嵌入显示颜色不是车道实例归属。新增聚类、曲线拟合或数据集评分，需要定义算法并单独验证，不能从主机测试通过推导而来。
