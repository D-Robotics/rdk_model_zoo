# ResNet50 模型下载

在本目录运行下载脚本：

```bash
bash download_model.sh s100
```

脚本会将 S100 HBM 文件下载到 `./s100/`：

| 模型 | URL |
| --- | --- |
| `resnet50_224x224_nv12.hbm` | `https://archive.d-robotics.cc/downloads/rdk_model_zoo/rdk_s100/ResNet/resnet50_224x224_nv12.hbm` |

本 sample 使用公开 S100 HBM 模型。
