# DiffusionDrive Model Files

Platform-specific HBM files use these paths:

| Platform | March | Model path |
| --- | --- | --- |
| RDK S100P | `nash-m` | `s100p/diffusiondrive_r34_256x1024_s100p.hbm` |
| RDK S600 | `nash-p` | `s600/diffusiondrive_r34_256x1024_s600.hbm` |

The filename follows `<model_name>_<input_resolution>_<chip_name>.hbm`. The camera resolution is `256x1024`; the model also accepts LiDAR, ego status, and diffusion noise tensors.

HBM binaries are ignored by Git. The downloader auto-detects the board and uses the public Model Zoo archive:

```bash
bash download_model.sh
CHIP=s100p bash download_model.sh
CHIP=s600 bash download_model.sh
```

Both artifacts are generated by OpenExplorer v3.7.0 using INT16-first PTQ and max calibration. GridSample remains INT8 as required by the toolchain, and all segments run on the BPU. The downloader verifies the selected file against `SHA256SUMS`.
