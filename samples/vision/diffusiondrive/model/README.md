# DiffusionDrive Model Files

Place the S600 model at:

```text
s600/diffusiondrive_r34_256x1024_s600.hbm
```

The filename follows `<model_name>_<input_resolution>_<chip_name>.hbm`. The camera resolution is `256x1024`; the model also accepts LiDAR, ego status, and diffusion noise tensors.

The HBM binary is ignored by Git. To fetch it from an internal or released location:

```bash
MODEL_URL=<accessible-hbm-url> bash download_model.sh
```

The tested artifact is generated by OpenExplorer v3.7.0 for `nash-p` / S600 using full-INT16 PTQ and max calibration. Verify downloaded files with `sha256sum -c SHA256SUMS` from this directory.
