# DiffusionDrive Test Data

`reference_inputs.npz` contains one deterministic NAVSIM mini sample using the public HBM tensor interface:

| Tensor | Shape | Data type | Description |
| --- | --- | --- | --- |
| `camera` | `1x3x256x1024` | float32 | Normalized three-camera mosaic |
| `lidar` | `1x1x256x256` | float32 | LiDAR BEV histogram |
| `status` | `1x8` | float32 | Ego status and driving command |
| `noise` | `1x20x8x2` | float32 | Fixed truncated-diffusion noise |

`reference_outputs.npz` stores the corresponding PyTorch float32 outputs for evaluator regression. `reference_result.png` is generated on RDK S600 with the accepted full-INT16 HBM model.

The noise tensor is intentionally fixed so repeated sample runs are deterministic.

## Additional Cases

Five packaged cases are available under `case_000`, `case_017`, `case_042`, `case_073`, and `case_099`. Each directory contains:

| File | Description |
| --- | --- |
| `inputs.npz` | Four deterministic float32 model inputs |
| `reference_outputs.npz` | Corresponding PyTorch float outputs |
| `result.png` | Visualization generated by the accepted S600 HBM |

| Case | Scene | Predicted agents | BEV pixel agreement | BEV mean IoU |
| --- | --- | ---: | ---: | ---: |
| `case_000` | Wide signalized intersection | 7 | 0.944061 | 0.868425 |
| `case_017` | Signalized intersection with nearby traffic | 7 | 0.944000 | 0.761217 |
| `case_042` | Dense multi-lane urban traffic | 13 | 0.966736 | 0.728740 |
| `case_073` | Open straight boulevard | 6 | 0.966156 | 0.876931 |
| `case_099` | Wide intersection with many detected agents | 14 | 0.958862 | 0.899669 |

Mean IoU includes every class present in either output. In `case_017` and `case_042`, a handful of class-4 pixels therefore has a disproportionate effect on the macro average; pixel agreement is also reported for context.

Run one case from `runtime/python`:

```bash
python3 main.py \
  --input-npz ../../test_data/case_017/inputs.npz \
  --output-npz results/case_017/outputs.npz \
  --output-image results/case_017/result.png
```

Run all five with `bash run_all_cases.sh`.
