# ASR 模型转换

[English](README.md) | 简体中文

<a id="source-model"></a>
## 源模型
本 sample 使用 Wav2Vec2 ASR 模型。已发布的 S100/S600 HBM 与固定词表可通过[模型文档](../model/README_cn.md)获取。本目录不提供 checkpoint→HBM 脚本：请以外部输入方式准备 Wav2Vec2 checkpoint、导出器和各目标的 OE 配置，并记录 checkpoint 链接/版本、结构与训练配置。

<a id="toolchain-targets"></a>
## 工具链与目标
活动清单分别发布 S100 和 S600 HBM。使用与各制品匹配的 OE/编译器版本和目标配置，并记录所用版本。不能将 S100P 当成 S100，也不能通过改 HBM 文件名适配其他板卡。

<a id="export"></a>
## 导出
导出输入包括精确 checkpoint、模型结构/配置、词表顺序、前处理契约、导出依赖版本和 ONNX opset。运行时预期输入 float32 `[1,30000]`、输出 `[1,T,3503]` logits；T 从实际导出模型观察，不能借用其他 Wav2Vec2 模型的值。比较文本前先确认 blank ID 0 和固定词表。

<a id="calibration"></a>
## 校准
准备校准集并记录来源、许可、划分。校准数据遵循运行时 16 kHz 单声道、独立窗口、方差加 1e-5、先归一化再补零的前端契约。随附短录音只作功能示例，不是代表性校准集或精度数据集。记录重采样方法和末块处理。

<a id="compile"></a>
## 编译
在 OE 环境中使用匹配目标的配方完成编译。核对编译器输入输出属性，并随运行记录模型/配置/数据/工具链哈希。整数输出必须提供运行时可处理的真实 SCALE 元数据，不能凭文件名虚构 scale。

<a id="validation"></a>
## 验证
先对同一前处理波形比较源模型与导出 logits，再结合真实量化元数据比较编译产物。数值容差与解码模式分别报告；即使 logits 完全相同，CTC 和 legacy 文本也可能不同。数据集 CER 需要有标注转录和明确文本归一化政策。

<a id="artifacts"></a>
## 产物
完整交付应包括 checkpoint 身份/许可、ONNX/哈希、有序词表/哈希、前端配置、校准清单、各目标编译配置/日志、HBM/哈希及验证报告。

<a id="known-gaps"></a>
## 准备要求
checkpoint/导出配方、校准语料、编译器版本/配置以及源模型/导出/HBM 验证均需作为外部输入准备，本目录不提供。使用已发布 HBM 时，按模型文档中的推理流程运行。
