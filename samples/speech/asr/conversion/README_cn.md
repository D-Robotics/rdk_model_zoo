# ASR model conversion

[English](README.md) | 简体中文

<a id="source-model"></a>
## 源模型
S 源实现将模型标为 Wav2Vec2 ASR，但未提供完整 checkpoint→HBM 配方。[模型文档](../model/README_cn.md)支持使用已发布 HBM 与固定词表；能下载 HBM 不代表已有可导出的源权重。本目录没有已核实的 checkpoint 链接、版本或训练配置。

<a id="toolchain-targets"></a>
## 工具链与目标
活动清单分别发布 S100 和 S600 HBM。可复现转换需要各目标对应的 OE/编译器版本及配置，源占位资料尚不足以核定。不能将 S100P 当成 S100，也不能通过改 HBM 文件名适配其他板卡。

<a id="export"></a>
## 导出
现有材料不足以执行导出。需补齐精确 checkpoint、模型结构/配置、词表顺序、前处理契约、导出依赖版本和 ONNX opset。运行时预期输入 float32 `[1,30000]`、输出 `[1,T,3503]` logits；T 必须从实际导出模型观察，不能借用其他 Wav2Vec2 模型的值。比较文本前先确认 blank ID 0 和固定词表。

<a id="calibration"></a>
## 校准
没有随源提供的校准集或生成脚本。后续数据集需记录来源、许可、划分，并对齐 16 kHz 单声道、独立窗口、方差加 1e-5、先归一化再补零的前端契约。随附短录音只作功能示例，不是代表性校准集或精度数据集。需明确重采样方法和末块处理。

<a id="compile"></a>
## 编译
目前没有经过核实、可执行的编译配置和命令。应取得对应目标的完整配方，核对输入输出属性，记录模型/配置/数据/工具链哈希后再发布复现命令。整数输出必须提供运行时可处理的真实 SCALE 元数据，不能凭文件名虚构 scale。

<a id="validation"></a>
## 验证
先对同一前处理波形比较源模型与导出 logits，再结合真实量化元数据比较编译产物。数值容差与解码模式分别报告；即使 logits 完全相同，CTC 和 legacy 文本也可能不同。数据集 CER 需要有标注转录和明确文本归一化政策。本轮尚未执行 OE 编译或真实模型等价验证。

<a id="artifacts"></a>
## 产物
完整交付应包括 checkpoint 身份/许可、ONNX/哈希、有序词表/哈希、前端配置、校准清单、各目标编译配置/日志、HBM/哈希及验证报告。此目录仅有说明，不声称上述缺失产物已经存在。

<a id="known-gaps"></a>
## 已知缺口
尚缺精确权重/导出配方、校准语料、编译器版本/配置及真实源模型/导出/HBM 验证。[历史转换目录](../../../../platforms/s/samples/speech/asr/conversion/)保留供追溯。可沿运行时流程使用已发布 HBM，但下载并运行不等于完成模型转换。
