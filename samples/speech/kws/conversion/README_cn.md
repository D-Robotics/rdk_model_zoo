# KWS conversion availability

[English](README.md) | 简体中文

<a id="source-model"></a>
## 源模型

源中将模型描述为 PaddlePaddle/PaddleAudio 体系的 MDTC 关键词模型，但没有训练权重、导出脚本或权重摘要。原[转换页](../../../../platforms/s/samples/speech/kws/conversion/README_cn.md)只有占位内容。本目录明确缺失前提，不冒充转换配方。

<a id="toolchain-targets"></a>
## 工具链与目标

仅发布 S100 已编译 HBM，未记录可验收的编译器版本、模型配置或 X5/S100P/S600 适配。Runtime 前端版本不代表编译器兼容性。现有推理使用[发布模型](../model/README_cn.md)，不能直接照抄图像样例的编译命令。

<a id="export"></a>
## 导出前提

可复现导出需先取得精确唤醒词权重和架构、前处理定义、导出工具版本及图 I/O。记录权重/图 SHA-256、输入输出名称、形状和概率语义；如果最终输出已是概率，保留对应激活，统一运行时不会再次 sigmoid。

<a id="calibration"></a>
## 校准前提

没有提供代表性正负音频和有使用权限、独立划分的校准集。单个“hey snips”片段不足以作为校准或准确率证据。需匹配单声道 16 kHz PCM 缩放、60000 点截断/补零和固定 80-bin fbank，记录随机化、源 ID、前端版本及特征摘要。

<a id="compile"></a>
## 编译前提

由于图、工具链版本、目标配置和校准集缺失，这里不提供虚构的可执行编译命令。未来 S100 配方必须明确目标、特征布局、量化精度和最终输出语义，并保存编译日志及产物摘要；不能改名其他目标的 HBM 或发布未经验证的摘要。

<a id="validation"></a>
## 验证流程

先在独立正负数据上对照浮点图与原始模型，再比较编译模型的 metadata 和分数；分数容差、阈值判定、误唤醒/漏唤醒及延迟分别报告。主机 PaddleAudio 一致性只验证特征计算，不证明导出正确性或板端行为。

<a id="artifacts"></a>
## 后续完整配方应提供

权重/源码身份、导出命令、图契约、校准清单与特征、生效编译配置及日志、产物摘要、独立浮点/编译对照报告。本文不声称这些已经完成；现有 HBM 下载和历史性能仍可通过模型/评估说明使用。

<a id="known-gaps"></a>
## 已知缺口

固定源缺权重、导出、校准和编译输入，本轮没有新增 OE 编译或板测。统一样例保留这一边界，不虚构可复现性。取得真实前提后再做新转换；现有发布制品仍可在满足 SDK 检查的环境中使用。
