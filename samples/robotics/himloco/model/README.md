# Model Files

The RDK X5 model is downloaded into `model/bayes-e/`. Model binaries are not
stored in the repository.

| Model | File | Input | Output |
| --- | --- | --- | --- |
| HIMLoco Go2 | `himloco_go2_bayese_1x270.bin` | float32 `[1,270,1,1]` | float32 `[1,12,1,1]` |

## Download

```bash
bash download_model.sh
```
