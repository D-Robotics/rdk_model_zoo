<a id="directory"></a>
## Directory

`artifacts.json` indexes 32 `manifests/<profile>.json` files; `prepare.py` verifies files and prepares configurations.

<a id="preparation"></a>
## Preparation

Follow the [quick start](../README.md#quickstart) to download, verify the ZIP SHA256 and extract. Pass the model directory as `--source-dir`; configuration is written there by default. Optional `--output-dir` copies into a new directory. Every member is checked by size and full SHA256; mismatched existing files are rejected without overwriting user data.

<a id="accompanying-files"></a>
## Companions

Retain every vendor ZIP member. Packages normally contain a language HBM and embedding; VLM adds vision, ASR adds audio, and accelerated profiles add draft HBMs/embeddings plus an optional token map. Most profiles embed tokenizer/chat templates inside HBM and do not use Gemma external tokenizer/PLE requirements.

<a id="local-paths"></a>
## Deployment paths

```bash
MODEL_DIR=/data/Qwen3-0.6B_w8
python3 samples/llm/oellm/model/prepare.py --profile qwen3-0-6b-w8 --source-dir "$MODEL_DIR"
python3 samples/llm/oellm/model/prepare.py --profile qwen3-0-6b-w8 --output-dir "$MODEL_DIR" --check
```

Preparation writes `oellm_config.json`, `model-manifest.json` and `SAMPLE_LICENSE`. Absolute `work_dir` makes launch independent of the current directory.

<a id="formats-checksums"></a>
## Formats and checksums

Manifests record ZIP size/SHA256/ETag, member SHA256/CRC, actual HBM compiler and core counts. Configurations come from the same SDK and retain their original SHA256; preparation binds an absolute deployment directory and S600. File checking does not load Runtime.
