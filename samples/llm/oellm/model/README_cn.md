<a id="directory"></a>
## 目录

`artifacts.json` 索引 32 个 `manifests/<profile>.json`；`prepare.py` 负责校验与配置生成。

<a id="preparation"></a>
## 准备

按 [快速体验](../README_cn.md#quickstart) 下载并核对 ZIP SHA256，再解压。将解压后的模型目录作为 `--source-dir`；缺省直接在该目录生成配置，指定 `--output-dir` 可复制到新目录。每个文件均按大小和完整 SHA256 校验。已存在但不匹配的文件会报错，不覆盖原数据。

<a id="accompanying-files"></a>
## 伴随文件

保留官方 ZIP 中所有文件。通常包含语言 HBM 与 embedding；VLM 另含视觉 HBM，ASR 另含音频 HBM，加速变体另含草稿 HBM、草稿 embedding 和可选 token 映射。多数配置的 tokenizer/chat template 已嵌入 HBM，不能套用 Gemma 的外置 tokenizer/PLE 文件要求。

<a id="local-paths"></a>
## 部署路径

```bash
MODEL_DIR=/data/Qwen3-0.6B_w8
python3 samples/llm/oellm/model/prepare.py --profile qwen3-0-6b-w8 --source-dir "$MODEL_DIR"
python3 samples/llm/oellm/model/prepare.py --profile qwen3-0-6b-w8 --output-dir "$MODEL_DIR" --check
```

生成 `oellm_config.json`、`model-manifest.json` 和 `SAMPLE_LICENSE`。`work_dir` 为绝对路径，运行时不依赖启动目录。

<a id="formats-checksums"></a>
## 格式与校验

每个清单保存官方 ZIP 大小、SHA256、ETag、成员 SHA256/CRC、真实 HBM 编译器与核心数。配置来自同版本 SDK，保留其原文 SHA256；准备时只把部署目录改为绝对路径并显式绑定 S600。文件校验不加载 Runtime。
